# Mis Finanzas

Aplicación móvil desarrollada con [Flet](https://flet.dev) y [Supabase](https://supabase.com) para el control y gestión inteligente de ingresos y gastos personales en Soles (S/).

## Características
* **Offline-First:** Guarda y consulta tus movimientos al instante sin necesidad de internet.
* **Sincronización en la nube:** Respaldo automático con Supabase y autenticación con Google.
* **Dashboard visual:** Tarjetas de balance, distribución de gastos por sobres y flujo de caja mensual.
* **Gestión completa:** Creación, edición y eliminación de movimientos con confirmación de seguridad.
